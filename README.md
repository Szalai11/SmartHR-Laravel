# 🚀 SmartHR - Application Web de Gestion RH & Recrutements

SmartHR est une application web full-stack développée sous Laravel dans le cadre de mon projet de soutenance (Licence / Bachelor Informatique). Elle permet d'automatiser et de centraliser la gestion des ressources humaines, le suivi des candidatures, les contrats et les congés au sein d'une structure.

---

## 🛠️ Technologies Utilisées

* Backend : PHP 8+, Laravel
* Frontend : Blade Templates, Tailwind CSS / HTML5, CSS3, JavaScript
* Base de données : MySQL
* Outils & Versioning : Git, GitHub, XAMPP, Composer

---

## 📌 Fonctionnalités Principales

* Module Recrutement : Publication des offres et suivi des candidatures.
* Gestion du Personnel : Fiches employés détaillées et suivi de carrière.
* Gestion des Congés & Contrats : Demandes de congés et édition de documents RH.
* Base de données : Déploiement du schéma via migrations et script SQL (rh_app.sql).

---

## ⚙️ Installation en Local

1. Cloner le dépôt :
   git clone https://github.com/Szalai11/SmartHR-Laravel.git
   cd SmartHR-Laravel

2. Installer les dépendances PHP :
   composer install

3. Générer la clé d'environnement :
   php artisan key:generate

4. Lancer le serveur :
   php artisan serve
